## Кратко о проекте

Проект моделирует работу сервисного центра по ремонту бытовой техники с использованием дискретно-событийного моделирования.

Заявки поступают от клиентов через случайные интервалы времени по равномерному распределению. Продолжительность обслуживания определяется по экспоненциальному распределению.

Если есть свободный мастер, заявка сразу передаётся ему на обслуживание. Если все мастера заняты, заявка помещается в общий буфер.

Постановка заявок в буфер и выбор свободного мастера выполняются по кольцу с использованием двух независимых указателей.

При переполнении буфера удаляется самая старая заявка, а новая занимает её место. Удалённая заявка учитывается как отказ.

После завершения обслуживания диспетчер выбора проверяет буфер. Если в нём есть заявки, выбирается последняя поступившая по принципу LIFO.

## Событийная модель

Моделирование основано на обработке двух типов событий:

- `REQUEST_GENERATED` - поступление новой заявки;
- `SERVICE_COMPLETED` - завершение обслуживания заявки.

Класс `Simulation` управляет процессом моделирования, а `EventCalendar` хранит будущие события в порядке модельного времени.

## Режимы моделирования

**Пошаговый режим (ОД1)**

После каждого шага отображаются текущее модельное время, обработанное событие, состояние буфера, состояние мастеров, кольцевые указатели и статистика.

**Автоматический режим (ОР1)**

События обрабатываются автоматически. После завершения моделирования формируются две итоговые таблицы с результатами работы системы.

## Реализация

Программная реализация модели СМО по варианту №16 находится в разработке.

Планируется реализовать:
- генерацию заявок и обслуживание по заданным распределениям;
- кольцевые алгоритмы постановки заявок и выбора мастеров;
- вытеснение самой старой заявки при переполнении;
- выбор заявок по LIFO;
- календарь событий;
- пошаговый и автоматический режимы;
- сбор статистики и формирование итоговых таблиц.
