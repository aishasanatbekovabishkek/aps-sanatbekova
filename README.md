## Формула варианта

`ИБ ИЗ2 ПЗ1 Д1ОЗ1 Д1ОО3 Д2П2 Д2Б2 ОР1 ОД1`

## Расшифровка варианта

- **ИБ** — бесконечный источник заявок.
- **ИЗ2** — равномерный закон генерации заявок.
- **ПЗ1** — экспоненциальный закон времени обслуживания.
- **Д1ОЗ1** — постановка заявки в буфер по кольцу.
- **Д1ОО3** — при переполнении буфера выбивается самая старая заявка.
- **Д2Б2** — выбор заявки из буфера по принципу LIFO.
- **Д2П2** — выбор свободного прибора по кольцу.
- **ОР1** — сводная таблица результатов в автоматическом режиме.
- **ОД1** — календарь событий, буфер и текущее состояние системы в пошаговом режиме.

## Бизнес-домен

В качестве бизнес-домена рассматривается сервисный центр по ремонту бытовой техники.

Соответствие элементов СМО бизнес-домену:

| Элемент СМО | Бизнес-сущность |
|---|---|
| Источник | Клиент сервисного центра |
| Заявка | Заявка на ремонт бытовой техники |
| Буфер | Очередь заявок на ремонт |
| Прибор | Мастер сервисного центра |
| Диспетчер постановки | Система приёма заявок |
| Диспетчер выбора | Система распределения заявок между мастерами |
| Обслуживание | Ремонт бытовой техники |
| Выход из системы | Завершённая заявка |

## Логика работы системы

Клиент формирует заявку на ремонт бытовой техники.

Если имеется свободный мастер, заявка может быть сразу передана на обслуживание.

Если все мастера заняты, заявка помещается в буфер по кольцевому принципу согласно `Д1ОЗ1`.

Если буфер полностью заполнен, согласно `Д1ОО3` из него удаляется самая старая заявка, а новая заявка занимает её место.

При освобождении мастера из буфера выбирается последняя поступившая заявка согласно принципу LIFO (`Д2Б2`).

Свободный мастер выбирается по кольцу согласно `Д2П2`.
