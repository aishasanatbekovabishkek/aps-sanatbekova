## Кратко о проекте

Проект моделирует работу сервисного центра по ремонту бытовой техники.

Заявки поступают от клиентов и передаются свободным мастерам. Если все мастера заняты, заявки помещаются в буфер. Постановка в буфер и выбор свободного мастера выполняются по кольцевому принципу с использованием указателей.

При переполнении буфера удаляется самая старая заявка, а при освобождении мастера из буфера выбирается последняя поступившая заявка по принципу LIFO.
